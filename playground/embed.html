2What the host wires up

In driven mode the component asks the server what to do — a prompt and an output schema, with no model called anywhere — hands it to you, and commits whatever you return. That is the whole integration. 

const el = document.querySelector('nexcraftviz-chat');

el.onPropose = async ({ prompt, skill }) => {
  // prompt.system, prompt.user, prompt.output_schema
  return await myModel(prompt);        // your model, your key, your logs
};

This page stands in for myModel with a tiny rule-based stub, so the demo runs with no API key. Watch the log: the operations it returns are the same ones a real model would emit, and the appliers do not care which.
