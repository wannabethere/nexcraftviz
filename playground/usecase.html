1The table renders first

Rows arrive and the table is built straight from them — column roles and value ranges pick the renderers. No model runs, so this costs nothing and cannot be wrong about what the data contains. The user is reading real results while the chart is still being generated.

3Rules pick the chart

Asked: Which business units are behind on compliance training against the 90% target?. The shape settles most of it before a model is involved; the question only nudges the ranking.

ChartScoreWhy
grouped_bar0.95two dimensions compare side by side (matches the question's intent)
stacked_bar0.85two dimensions as composition within each category (matches the question's intent)
table_with_cells0.801 per-row series column(s) belong in a rich table
bar0.72rank by business_unit alone and ignore the second dimension
heatmap0.65the same two dimensions as a matrix (matches the question's intent)
